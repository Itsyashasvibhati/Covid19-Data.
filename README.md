# 🦠 COVID-19 Advanced Data Science Dashboard

## 📌 Project Overview

This project is an **interactive COVID-19 Data Science Dashboard** built using Python and Streamlit. It analyzes global pandemic data and presents insights through **advanced visualizations and real-time filtering**.

The dashboard allows users to explore trends, compare countries, and understand the spread of COVID-19 using multiple graph types.

---

## 🚀 Features

* 📊 Interactive Dashboard UI
* 🌍 Country-wise Filtering
* 📈 Trend Analysis (Line Graph)
* 📊 Bar Chart (Top Countries)
* 🥧 Pie Chart (Case Distribution)
* 🔍 Scatter Plot (Cases vs Deaths)
* 📊 Area Chart (Growth Analysis)
* 🗺️ Global Map Visualization

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```
git clone https://github.com/Itsyashasvibhati/covid-dashboard.git
cd covid-dashboard
```

---

### 2️⃣ Install Dependencies

```
pip install pandas plotly streamlit
```

---

### 3️⃣ Run the Application

```
python -m streamlit run app.py
```

---

### 4️⃣ Open in Browser

```
http://localhost:8501
```

---

## 🧠 Working of the Project

1. Data is loaded using Pandas
2. Data is cleaned and preprocessed
3. User selects a country using sidebar
4. System filters data dynamically
5. Visualizations are generated using Plotly
6. Results are displayed in an interactive dashboard
